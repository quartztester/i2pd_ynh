i2pd is a lightweight C++ implementation of an I2P router — the same anonymous overlay network the Java router serves, with a much smaller footprint (tens instead of hundreds of megabytes of RAM).

Like every I2P node it shuttles encrypted, single-hop tunnels for other users; by default this package also registers it as a "floodfill", answering the network's distributed-database queries (the main way to volunteer capacity — turn it off in `/etc/i2pd/i2pd.conf` for a plain relay). The webconsole (peers, tunnels, bandwidth, addressbook) is served on its own domain behind YunoHost's SSO; the HTTP proxy, SOCKS proxy and SAM bridge it exposes listen on localhost only, for local applications and containers.

Nothing is proxied for website visitors. A floodfill answers many small queries per second, so expect a modest but steady share of bandwidth and a somewhat higher uptime expectation from the network. The package installs upstream's official release deb (sha256-pinned) with its own systemd unit and AppArmor profile, and it can run side by side with the `java_i2p` app: the webconsole and peer ports never overlap, and the shared upstream proxy/SAM defaults (4444/7656) are asked at install time so you can steer i2pd onto free ports.
